# 공문서 표기 핵심 (행정업무운영편람 기준 요약)

값을 넣거나 원고를 쓸 때 아래 표기를 따른다. 양식에 별도 예시 표기가 있으면 양식을 우선한다. 세부 검수는 `lint`(kordoc 표기법 규칙)가 한다.

| 항목 | 바른 표기 | 피할 표기 |
| --- | --- | --- |
| 날짜 | `2026. 10. 15.` (연·월·일 글자 대신 온점, 마지막에도 온점) | `2026.10.15`, `2026-10-15`, `2026. 10. 15일` |
| 요일 | `2026. 10. 15.(목)` | 요일-날짜 불일치(검수에서 확인) |
| 시간 | `14:00` (24시각제, 쌍점) | `오후 2시`, `14시` |
| 기간 | `2026. 10. 1.~10. 8.` (물결표 앞뒤 붙임) | `2026. 10. 1. ~ 10. 8.` |
| 금액 | `금30,000,000원(금삼천만원)` — 공고·계약은 한글 병기 | 숫자만 쓰고 병기 누락(계약·입찰 문서) |
| 쌍점 | `관련: 인사총무팀-1234` (앞말에 붙이고 뒤 한 칸) | `관련 : …` |
| 항목 기호 | `1.` → `가.` → `1)` → `가)` → `(1)` → `(가)` → `①` → `㉮` | 기호 섞어 쓰기 |
| 붙임 | 본문 다음 줄 `붙임  1. ○○계획 1부.` 둘 이상이면 번호 | “첨부:” |
| 끝 표시 | 본문(또는 붙임) 끝에서 2타 띄우고 `끝.` | 생략 |
| 외래어·약어 | 우리말을 먼저, 원어는 괄호: `업무 AI 전환(AX)` | `AX(업무 AI 전환)` |
| 연도 | `연도`(두음법칙) | `년도`(단독 사용) |

## 문체

- 기안문 본문: “~하오니 협조하여 주시기 바랍니다.”처럼 정중한 공문 문체.
- 보고서·계획서: 개조식 명사형 종결(“~ 추진”, “~ 예정”), 서술형 “~다.” 지양.
- 한 항목에 한 내용. 수치는 단위와 기준일을 함께.
- 생성형 AI 초안에서 흔한 줄표(—), 과한 굵게 강조, 번역투 문장은 쓰지 않는다(lint의 `AI_*` 규칙이 잡는다).
